# 🌍 Elliria's TIL
Welcome! This repository, inspired by other TIL repositories like it that were arguably popularized by [Simon Willison's TIL on GitHub](https://github.com/simonw/til), is a globally-accessible external brain that was originally written for an audience of one. It serves as my personal **Today I Learned (TIL)** database — a collection of snippets, system blueprints, and practical breakthroughs spanning a wide array of domains and topics. Because curiosity doesn't stop at a single category, it has no strict boundaries. It reflects a lifelong pursuit of bottom-up systematizing, where crafts, physics, sciences, software engineering, and more are treated with equal weight. Perhaps you'll find it useful, too.

To maintain order in this sprawling collection:
* The contents are arranged by category.
* Files that fit into more than one category will appear in more than one category.
* Each file contains tags to help with [searching the archive](https://github.com/search?q=repo%3Aelliria%2Ftil&type=code).
